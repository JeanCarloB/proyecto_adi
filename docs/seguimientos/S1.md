## Bloqueos

- El XAMPP local tenía PHP 8.0 y no sirve con `mongodb/mongodb` 2.4; se resolvió con PHP 8.2 y la extensión `mongodb` 2.4 (pasos en [`docs/instalacion.md`](../instalacion.md)).
- El DDL se empezó en PHP y se pasó a scripts de `mongosh` para poder ejecutarlo fuera de la aplicación.

## Decisiones técnicas

- **Perfil A (solo MongoDB Atlas):** las tres evidencias de profundidad son volumen (≥ 100 000 ventas), funciones avanzadas (aggregation, JSON Schema, índices compuestos, únicos y TTL) y comparación experimental (con y sin índice).
- **MongoDB Atlas (M0, AWS Oregon):** acceso solo desde la IP del servidor y la URI fuera del repositorio, como pide el enunciado.
- **PHP 8.3 con `mongodb/mongodb`:** es lo que tiene el servidor Virtualmin.
- **Montos en `Decimal128` y fechas como `date`** en todas las colecciones.
- **Despliegue por `git pull`** con deploy key de solo lectura; el `.env` del servidor no se versiona.
